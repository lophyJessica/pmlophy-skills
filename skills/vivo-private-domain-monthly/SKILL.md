# 外销私域月度盘点（WhatsApp 好友与账号）

每月固定要跑的活：拉上一个月末的私域三项指标，与上月对比，喂给上线报告 / 月报。当用户说「拉一下 X 月的私域数据」「留存/导入/导购数这个月多少」或上线报告私域页要更新时用本 skill。

## 三项指标口径（铁律，业务定过，不得自行调整）

| 指标 | 定义 | 取数位置 |
|---|---|---|
| 留存用户 | 账号对应好友列表数据，**只算用户未删除的** | 好友列表 |
| 导入用户 | 账号对应好友列表数据，**不区分用户是否已删除** | 同一个好友列表，只是不过滤删除状态 |
| 私域导购数 | 手机卡关联的 WhatsApp 账号且**已授权**，**不区分是否已分配给导购** | WhatsApp 账号列表 |

易错点：
- **导入 ≥ 留存**。若算出来留存大于导入，说明筛选条件弄反了，重来。
- 私域导购数的口径是「已授权账号数」，不等于「实际在用的导购人数」。1027 版上线报告里写的「108 名导购」是另一口径，两个数并存时要点明区别，不能混着讲。
- 分国家取，不要只拿合计。国家至少覆盖 印尼 / 马来 / 孟加拉，列表里出现的其他国家一并列。

## 数据源页面

- 好友列表：`https://scrm.vivo.com/main/content/content/whats/account/friends`（外销生产站，带 .cn 的是内销，别搞混）
- WhatsApp 账号列表：从左侧菜单进，URL 每次让 agent 现场报回来并记下
- 页面支持切换战区，取每个国家前都要重新刷一次筛选，不许用上一个国家的数据顶替

### 战区结构（2026-11-04 实测，不切战区会直接取不到数）

顶栏「切换」跳的是**整页** `/main/area`（租户列表），不是下拉。四个战区，各战区国家下拉只显示本战区国家：

| 战区 | 国家（好友列表「账号所属国家」下拉） |
|---|---|
| 东南亚战区 | 泰国、马来西亚、菲律宾、中国台湾、越南、中国香港、新加坡、缅甸、柬埔寨（9 国） |
| 海外直营 | 印尼（子租户列表写「印度尼西亚」，筛选下拉写「印尼」） |
| 南亚战区 | 孟加拉 |
| 非洲战区 | 肯尼亚、埃及 |

四战区合计 13 国，加印度即报告口径的 14 国。**只在默认的东南亚战区下找印尼 / 孟加拉是找不到的**，不是权限问题也不是数据缺失。走法：点战区名 → 子租户列表 → 点首行（与战区同名、special 行）进入本战区 → 再开好友列表看下拉。

### 好友列表页的已知限制（2026-11-04 实测）

- **没有添加时间筛选**，列表也无「添加时间」列，只有「数据同步时间」→ 拿不到「截至某月末」的截面，只能取当前快照
- **「Whats账号删除状态」只是一列，没有筛选项——因为不需要筛：好友列表页面里的数据本身就是全部未删除的**（2026-11-04 用户当场纠正）。所以好友列表的「共 xxx 条」总数**直接就是留存用户数**，不用任何筛选，取数时别去找删除状态筛选
- 总条数在分页区，文案为「共 xxx 条」，每页可选 10/20/50/100

含义：**留存用户 = 好友列表总数，可直接取**。真正取不出来的是**导入用户（不区分删除）**——页面只有未删除数据，已删除的那部分不在列表里。业务给的 9 月两数（留存 59,609 / 导入 59,994，差 385）里的「导入」**不可能从这个页面读出**，需要导全量后在 Excel 里算或找数仓。遇到这种情况不要翻页硬数，**直接向业务要当月原始导出件**。

### WhatsApp 账号列表页

URL：`https://scrm.vivo.com/main/content/content/whats/account/list`（左侧 whats管理工具 → Whats账号列表）。
筛选：账号所属国家、账号对应手机号、授权状态（已授权 / 待授权）。
**Tab：待分配 / 已分配 是页签形式（不是筛选下拉），总数分 Tab 各自展示**——2026-11-04 用户截图确认。取「私域导购数」口径（已授权、不区分是否已分配）时，必须两个 Tab 分别按国家取已授权数再相加，只取一个 Tab 会少算。
「添加时间」只是列表列，不是筛选项。

## 取数流程（月度固定）

1 **先摸结构**：报出筛选控件清单（名称/类型/默认值/全部下拉选项）、分页区实际文案（总条数是「共 xxx 条」还是「Total xxx」）、有无时间筛选。
2 **一个国家试算**：拿印尼分别取「不区分删除」与「仅未删除」两个数，与上月基线对一眼，量级对得上再往下走。
3 **全量拉取**：逐国刷筛选 → 读好友列表两个数 + 账号列表已授权数。
4 **落盘**：`08-相关资料/产品审计/私域月度盘点/私域数据-YYYYMM.tsv`，每页追加写，同目录维护 `抓取进度.txt`。
5 **对账**：与上月做逐项差值，别只报当月数。

历史月份文件不改，新月份只新增文件——否则趋势不可信。

## 时间口径这个坑必须先问清

页面**不一定有「添加时间」筛选**。

- 有时：把区间筛到 `年初 ~ 目标月末`，拿到的才是「截至 X 月」。
- 没有时：拉出来的是**当前时点快照**，会包含下个月头几天的量。此时必须在产物和汇报里写明「当前时点快照，非月末值」，不能当月末数用，也不能直接和上月比环比。

过去吃过亏：拿当前快照当月末值报，环比虚高，被业务当场问住。

## Cursor 取数指令模板

## 归档与回写

- 产物目录固定 `08-相关资料/产品审计/私域月度盘点/`
- 上线报告要引用时，先看报告里现成那句写的是哪个时点，改数字的同时改时点，别只改数
