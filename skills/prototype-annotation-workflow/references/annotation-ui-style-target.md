# 标注 UI 目标样式拆解（对标实现，2026-08-08）

来源：用户提供的两张截图（别人的实现——基于维他命 Skill 自己摸索调出来的，无源码）。
目标：forge 项目 annotation-kit runtime 从"徽章+弹窗"升级为"完整标注面板"。待办中，实现时对照本文件。

## 第一张图：页面状态
- 页面顶部工具栏有"原型标注"按钮（白色，带文档/列表图标，与"+新增"绿色按钮、"导出"按钮并列）
- 页面本身有"桌面端操作引导"（流程步骤高亮：05 采购入库、08 供应商应付）——与本需求无关，只是背景

## 第二张图：标注面板（核心）
- **浮层面板**：白底卡片 + 阴影 + 圆角，覆盖在页面上（非侧边栏，可理解为居中/右上浮层）
- **头部**：气泡图标 + 标题"原型标注" + 条目总数徽章（灰色圆，数字 9）+ 关闭 X
- **副标题**："点击条目定位页面中的对应区域"
- **页签栏**：全部 / 页面 / 交互（当前，绿色高亮白字）/ 规则 / 字段 / 待确认
- **条目卡片**：
  - 序号徽章：绿色圆形数字（2、4……）
  - 标题："新增在途采购单"、"状态页签"
  - 类型标签：绿色小标签"交互"（对应页签分类）
  - 摘要：一行业务描述（"进入新增页，创建一个新的在途采购单。"）
  - 底部："展开详细说明"（向下 chevron + "5 项"）/ 展开后变"收起详细说明"（向上 chevron + "16 项"）
- **展开详情**（结构化规则，Markdown/列表渲染）：
  - 示例："页签通用行为" + 子项：全部（显示所有可见在途采购单）、数量徽标（显示当前状态单据数，随状态变更和删除更新）、切换结果（切换页签只显示该状态记录并清空当前勾选）、状态筛选（选中特定状态页签后隐藏查询区的状态下拉，避免重复筛选）、状态说明（全部=显示所有状态单据；草稿=已保存未提交审核，可查看/编辑/删除）
- **滚动**：面板右侧纵向滚动条（内容多可滚）
- **定位**：点击条目 → 页面滚动/高亮到对应 data-anno 区域

## 实现要点（给 Cursor 的指令要点）
1. runtime.js：从"点徽章弹窗"改为"面板模式"——面板开关按钮（页面顶部）+ 条目列表 + 页签过滤 + 展开收起 + 点击定位
2. 标注配置（annotation.config.json）加 type 元数据（page/interaction/rule/field/pending），供页签过滤
3. runtime.css：白底卡片/阴影/圆角/品牌绿高亮/tab 样式/展开动画/滚动条
4. 展开详情的结构化渲染（通用行为/数量徽标/切换结果/状态筛选/状态说明 这类子项列表）
5. 兼容既有 data-anno 锚点定位（点击条目 → scrollIntoView + 高亮）
