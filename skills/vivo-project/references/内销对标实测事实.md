# 内销 CMS 对标实测事实（1022 用户取证）

> 用途：内外销对齐与差异化说明的一手依据。凡新增对标结论，先查本文件，避免重复取证或与实配冲突。

## 一、用户行为页面（真系统实测）

| 项 | 内销实际 | 对外销的含义 |
|---|---|---|
| 菜单位置 | **活动计划 → 触达配置 → 用户行为**；同级：用户标签 / 机型分类 / 内容模板 / DMP人群 | 圈人原料类配置统一收在【触达配置】（触达/活动域），既不是权限中心，也不是工具中心。外销用户行为移出权限中心后，落点应靠触达侧 |
| 启用停用 | **有**——列表「启用状态」列 + 开关（蓝色开关形式）；操作列只有「编辑」，无“停用按钮 + 二次确认” | 启停能力保留（对齐），但形态应为开关，而非状态文字 + 停用按钮 + 二次确认 |
| 列表列 | 行为ID / 行为名称 / **行为维度** / 行为描述 / 启用状态 / 创建人 / 创建时间 / 操作 | 外销多出：行为编码、数据源表、用户标识、属性数；内销多出：行为维度（UNIONID/IMEI 等） |
| 筛选区 | **无**（无搜索、无状态筛选） | 外销加的“名称搜索 + 状态筛选”属自加能力，需在差异说明里给缘由 |

## 二、触达计划（内销）

- 形态：**节点式编排**（触发条件 → 目标人群 → +），非分步向导；下半是触发类型三态（定时型-定时触发 / 触发型-完成A / 触发型-完成A未完成B）
- 触发事件：“在[开始]-[结束]期间，用户完成以下行为” + 添加用户行为 → 行为在触发侧当“触发器”
- 目标人群：只做「选择人群」引用，不自圈人；新建人群 = 用户标签 / 用户行为 / DMP标签 三页签 + 固定条件 + 组织范围 + 用户关系
- 产品价值观原句：“人群洞察是触达的核心，系统将逐步培养您先洞察再触达的习惯”
- 人数预估：**两层**（圈选人数 / 可触达人数）——外销是三层（按渠道区分“有手机号/有邮箱”），有实抓证据，**不拿内销两层去改外销三层**

## 三、标签体系（内销）

- 标签库分「社群标签」「好友标签」两个页签；社群运营圈的是“群”（社群标签），与好友标签并行两条资产线
- 「自动打标」列表有**打标开关**列（开关的是打标规则，不是行为本体）

## 四、三层分离（内销架构判断，已入评审 PRD §1.1/§1.5）

1. 人群资产层（人群洞察）：标签/行为/DMP 条件 + 组织范围 + 用户关系 → 可复用、可命名的“人群”
2. 触达编排层（触达计划）：只“选择人群”，自己负责触发条件 + 推送时间
3. 社群线（社群运营）：另一套，圈“群”

同一套“用户行为”在两处复用：触发侧（触发事件）与圈人侧（新建人群的行为页签）。
