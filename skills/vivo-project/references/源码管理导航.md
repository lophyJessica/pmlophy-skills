## 二、对我们工作的直接含义

1. **内销对标只需一条来源**：内销 CMS 与企微工作台在同一个 monorepo（`cms-admin`），一次只读访问覆盖两端；再加 `qywx-h5` 覆盖导购侧 H5。内销**没有后端目录**——后端 SE 待定也不阻断对标（用户定：后端属技术侧，只作可选佐证）。
2. **外销自家材料优先于内销源码**：`global-cms-docs` 是我们自己的权威技术资产（架构图 / ER 模型 / 依赖拓扑 / **大数据表规范**），不受“内销源码只读、不外传”限制，可直接用来写“技术实现佐证”一节。要答“行为条件落在哪个服务、大数据表怎么定”，先查它，再谈内销源码。
3. **服务归口速记**：触达下发与消息 = `global-cms-target`；营销活动/策略 = `global-cms-campaign`；员工与组织 = `global-cms-employee`；对外统一 API = `global-cms-web`（BFF）。行为条件解析、预估人数这类问题大概率落在 target（与 `DmpTagConditionParseHandler` 同层）。
4. **技术栈一致性**：内销 cms-admin 与外销 cms-global 都是 Vue + TS，文件结构与组件写法可比，让 Cursor 做“形态与字段对照”时可以直接按同名目录/同类型组件对找。
