# 公司 AI 工具的模型档位与 Credits 倍率（2026-11 抄录）

刘龙飞反馈：国内 agent 把档位叫「极致/性能/经济/轻量」、又叠一层 x 倍率，看不懂。**记法只需两条：看倍率不看名字；倍率就是 credits 消耗系数。**

## 一、公司内部 agent（智能体，带「错峰折扣」提示条）

档位与倍率（上方一排，系统按档自动路由）：

| 档位 | 倍率 |
|---|---|
| Auto | 0.5x |
| 快速 | 0.8x |
| 极致 | 2.0x |
| 经济 | 0.0x |

具体模型（下方列表，点名即绕过档位，二者互斥）：

| 模型 | 倍率 |
|---|---|
| Sonus | 8.0x |
| Cantus | 4.0x |
| Kimi-K3.1-Pro | 1.0x |
| GLM-5.3 | 0.8x |
| Kimi-K2.8-Preview | 0.8x |
| Qwen3.8-Max | 0.5x（带折扣图标） |
| Qwen3.8-Flash | 0.1x |

关键量级：Sonus 8.0x 一次 = Qwen3.8-Flash 0.1x 八十次。页面顶部有「错峰折扣 X 后开启」倒计时，到点同请求更便宜，重活别在上午硬跑。

「企业专属」页签里是 GLM-5.3（0.8x），用户实测不稳定、基本调不起来，直接不要用；同样 0.8x 价位用 Kimi-K2.8-Preview。

## 二、企业版 coding 工具（Qoder 类）

档位映射（文案与上表不同，是两套命名）：

| 档位 | 对应模型 | 倍率 |
|---|---|---|
| 极致 Ultimate | Claude Opus 4.7 | 1.28x |
| 性能 Performance | Claude Sonnet 4.7 / ChatGPT 5.5 | 1.1x |
| 经济 Efficient | Gemini 3.1 Pro | 0.3x |
| 轻量 Lite | Qwen3 32B、Qwen3.6-Plus、DeepSeek-V4-Pro/Flash、GLM-5.1、Kimi-K2.6、MiniMax-M2.7 | 0.0x |
| Auto | 自动路由 | 1.0x |

## 三、选型规则（月额度 6000 credits）

| 场景 | 选什么 |
|---|---|
| 日常问答、查资料、读文档 | Qwen3.8-Flash 0.1x，或经济档 0.0x（基础模型，只能搬运） |
| 写代码、改代码 | Cantus 4.0x，或快速档 0.8x |
| 啃不动的重构 / 大批量代码推理 | Sonus 8.0x，掐着用，且等错峰折扣开启后 |
| 单次请求粗算 | Qoder Agent 模式 200K 上下文约 50 credits/次；Editor Agent 约 12（200K）/7（50K）；Ask 约 3-4 |

## 四、IM设计批评（用户原话，写产品时可用）

「搞什么倍率和经济、极致，用低、中、高、极高不好么」——他的观点：档位应表达质量层次（低/中/高/极高），成本用统一货币单位表达，不要用形容词混淆两件事。做 B 端 AI 产品的选型器时可以直接引用这条。
