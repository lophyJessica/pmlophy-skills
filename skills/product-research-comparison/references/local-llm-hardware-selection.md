# 本地大模型选型速查（2026-08，用户咨询沉淀）

用户场景：考虑买二手 M1 Ultra Mac Studio（64GB）跑本地大模型。选型逻辑 = 显存 × 质量权衡。

## 模型选择（按用途）
- 对话/办公：7-14B 量化（Q4/Q5）
- 编程辅助：14-32B
- 写作/翻译：7-14B 够用
- 推理/分析：32B+（要 4090/A6000）
- 最前沿：70B/123B（多卡/大显存）

## 首选模型（2026 主流）
- **Qwen3 系列**（阿里，中文强 + 开源 + 量化支持好）：
  - Qwen3-8B（Q4≈5GB）→ 16GB 显存可跑
  - Qwen3-14B（Q4≈9GB）→ 24GB 流畅
  - Qwen3-32B（Q4≈19GB）→ 4090/48GB
  - Qwen3-72B（Q4≈42GB）→ 双卡/96GB
- Llama 3.3 70B（英文强中文一般）、DeepSeek-R1 蒸馏版（推理强但慢）、GLM-4-9B（轻量办公）、Mistral Small 3.2（小显存）

## 硬件配置对应
- 最低能跑：16GB 内存 CPU 跑小模型（不推荐，极慢）
- 入门：RTX 4060 Ti 16GB / 4070 12GB → 8B/14B 流畅
- 甜点：RTX 4090 24GB → 32B 流畅
- 专业：双 4090 / RTX 6000 48GB / Mac 128GB 统一内存 → 70B+
- **Mac（Apple Silicon 关键优势）**：统一内存 = 显存；M1 Ultra 带宽 800GB/s（喂模型快，70B 无压力）；M1 Pro 200GB/s（14-32B）；M1 Max 400GB/s（32B 流畅 70B 勉强）

## Apple Silicon 内存档位（用户问过"Pro 有没有 64G"）
- M1（2020）：8/16GB
- M1 Pro：16/32GB（**最大 32，没有 64**）
- M1 Max：32/64GB（有 64）
- M1 Ultra：64/128GB（**只在 Mac Studio，无笔记本版**；跑 70B 的甜点）

## 跑起来（Ollama 一键）
```bash
brew install ollama && ollama serve
ollama run qwen3:14b   # 或 8b（更快）/ 32b（M3 24GB 勉强）
```

## 决策要点
- 跑大模型（32B+）主要吃**内存+带宽**（M1 Ultra 优势仍在，M1 单核弱但跑模型不落伍）
- 用户 Mac M3 24GB：14B 流畅、32B 勉强
- 二手 M1 Ultra 注意：Mac Studio 比笔记本值（散热/价格）；验机查电池/屏幕/主板维修史
- 用户定位：**"先了解，暂时没钱"**——纯知识储备，不急着买
