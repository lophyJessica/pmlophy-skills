# 用 Cursor 内置浏览器一次性摸清整个老系统（梭哈模式）

> 来源：2026-09-01/02 维生素课程"借助AI快速接手新项目"方法改写。适用：PM 接手**整个项目**（不是单模块）时，要快速摸清模块/页面/字段/状态/流程，产出能用于写 PRD、和研发沟通的结构化材料。

## 核心前提：用哪个浏览器工具

- **只有 Cursor 内置浏览器可用**（用户 0901/0902 实测：Codex 不行、ego 是 Mac 本地装不了 Windows、公司电脑只有 Cursor 内置浏览器带登录态）。
- 采集必须基于**当前已登录、有权限的会话**——填账号角色（如"全功能角色"）和租户/组织上下文（如"亚洲战区"）到提示词里，只采当前账号当前租户实际可见的导航。
- 提示词整体放**一个代码块**（用户偏好，别拆成多段散落）。

## 与维生素课程分步法的区别

课程原法是**分 3+ 段提示词、前一段输出喂后一段**（地图→页面→整理），稳但费交互。用户接手整个项目时偏好**梭哈**：一份提示词**一次跑完全项目、不按模块分批、不要求用户反复下发**。代价是单次任务重，所以必须内置：防跑飞停止条件 + 阶段间可续跑（地图落盘 JSON）。

## 单提示词结构（整项目版）

三阶段在**一份提示词内连续完成**：

1. **系统地图**：遍历顶部导航+左侧菜单+展开子菜单，记录每个入口页面。页面类型中文+英文码（list/detail/create/edit/form/report/settings/unknown…）。动态路由只留 1 个示例归纳 URL 模板（`:paramName`）。弹窗/抽屉无独立路由归"仅交互入口"。合并筛选/分页/hash/Tab 造成的重复。访问状态（已访问/需要权限/无数据…）+证据状态（已观察/待核实）。**输出 `<out>/01-菜单与页面地图.json+md`**——这是续跑/后续步骤的地图。
2. **全项目页面采集**：基于地图遍历所有页面，按类型记字段/Tab/按钮/状态/弹窗，不下业务结论。每页记录来源/页面ID/模块/URL/观察时间/账号角色/租户/默认状态。**输出 `<out>/02-页面采集/<模块>/<pageId>-<页面名>.md + 采集索引.md`**。
3. **全项目整理**：读全部页面记录 → 跨模块结构化产物（不分模块）：①页面功能矩阵 ②字段字典 ③单据与状态整理 ④待确认清单 ⑤**跨模块关系**（上下游引用/单据流转/共享字段来源）。每条结论标来源，证据区分 已观察/候选/待确认，同名字段差异并列保留不静默合并。**输出 `<out>/03-整理/`**。

## 铁律（提示词里必须写死）

- **只读边界**：不点删除/提交/确认/导出/保存/审核/付款/收货/发运/导入/批量；不退登录/不切账号租户语言时区；不猜 URL 隐藏菜单；新增/编辑页最多开一次确认路由不填写；下拉只查看不选择；没看到写"未观察到"不写"不存在"；登录墙/验证码/风控/付费墙记"需人工处理"跳过。
- **停止条件（防跑飞）**：页面 >10 秒无内容跳过；无权限/缺参数保留不猜；页面路由达上限（如 150 条）停发现新页；总时长超限（如 90 分钟）停并输出已有结果。
- **自检清单**：是否都来自实际可见导航无猜测？能否追溯来源？是否区分证据状态？是否保留同名字段差异？是否没把按钮名当业务结论？是否全程只读？是否一次跑完全项目未要求按模块分批？

## 用法补丁（防中途问题）

- 跑一半 Cursor 卡住/断 → 让它"**继续，从上次的 02-页面采集 接下去**"（地图已落盘能续跑，不用从头）。
- 跑完漏某模块 → 单独指那一模块补，别全量重跑。
- 完整可复制提示词母版在用户笔记库 `/root/notes/vitamin-course/10借助AI快速接手新项目，摸清老系统业务逻辑.md` + 改写成整项目的版本（本文件）+ forge 方法论的"整项目接手提示词"对话产物。
