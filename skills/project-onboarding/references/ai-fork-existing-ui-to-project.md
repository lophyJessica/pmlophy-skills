# 复刻已有系统前端到本地 React 项目 + 套方法论迭代

> 来源：2026-09-02 用户 vivo 负责 CMS+导购 H5，想把 CMS 测试环境前端复刻成本地项目，在上面套自己的 Forge 方法论做迭代设计。维生素课程 08「用 AI 复刻已有系统前端页面」改写为适配 Cursor+React 的版本。

## 适用场景 / 与「摸底 takeover」的区别

- **摸底（read-only 侦察）** → `references/ai-browser-legacy-takeover.md`：只读遍历整系统，产出 PRD 素材，不改代码。
- **复刻迭代（fork to local）** → 本文件：把已有系统**前端**复刻成本地可运行项目，当"研究基地/迭代原型"，套自己方法论（context→PRD→前端）在本地改，不碰正式环境。

## 关键决策（动手前先定）

1. **合规边界先行**：复刻的是**公司资产前端代码**，先确认①是否商业机密②测试环境可外带吗③会被 IT 审计吗。用户确认"测试环境随便造"才做；没确认前别整库拷公司代码到本地私人项目。CMS 是公司真实系统——业务逻辑/字段/状态机以公司真实业务为准，**别把 Forge 那种"自拟规则"硬套上去**（复刻用于理解现状 + 练习迭代，不用于改写公司业务事实）。
2. **复刻到哪档**：
   - 完整跑起来（拷源码/dist，npm run 看真实效果）——适合要改真实界面
   - 页面骨架复刻（Cursor 照页面/截图写静态 React 复刻，不依赖后端）——适合先摸结构再设计
3. **能否拿到源码**决定路径：有源码→直接拷到本地起项目最省事；只有页面→用 Cursor 内置浏览器让它照页面写 React 项目。

## 维生素课程的分法 vs 落地选择

课程 4 法（你有代码 / 只有截图 / Figma 稿 / 浏览器自动化）按手上材料选。用户场景（能登录测试环境、可能无源码）= **浏览器自动化复刻**。课程强调：复刻别只丢一张长图喊"像素级还原"——截图看不到下拉展开/弹窗层级/点击去向，AI 只能猜。要补关键状态截图 + 保留字段/操作/交互清单。

## React 项目复刻提示词（把课程"单页 HTML"版改成 React 项目版，整体一个代码块）

```markdown
# 用 Cursor 内置浏览器复刻 CMS 测试环境到本地 React 项目

你是资深前端视觉还原工程师。请使用 Cursor 内置浏览器（当前已登录、可访问 CMS 测试环境），把用户指定范围内的 CMS 页面复刻为本地可运行的 React 项目。

## 任务范围
- Cursor 内置浏览器中当前已打开、已登录的 CMS 测试环境页面是唯一视觉真源
- 用户指定页面清单，或"复刻当前打开的核心业务页面"
- 每个参考页面对应一个 React 页面组件；不自行扩展未指定的页面
- 页面范围冲突时先说明，只问 1 个关键问题

## 输出与技术约束
- 在指定输出目录创建 React 项目（若目录已有 React+TS 项目则沿用其结构/路由/组件/样式）
- 若目录空则创建最小 Vite + React + TypeScript 项目
- 不使用第三方 UI 组件库（或按项目已有组件库）；不引入不必要依赖
- 图标优先复用真实资源或内联 SVG，禁止 Unicode/Emoji 替代
- 禁止把整张截图当背景/CSS/图片直接展示

## 浏览器读取要求
对每个目标页面读取并还原：
- 页面标题、URL、当前视口尺寸
- 整体布局、导航层级、内容区、滚动方式
- 文字/字体/颜色/字号/间距/边框/阴影/信息密度
- 表格/表单/Tab/分页/弹窗/状态/可见操作
- 页面间已观察到的跳转关系

只执行浏览观察所需的安全操作（打开列表/详情/筛选/Tab/弹窗）。禁止保存/提交/删除/导出/退出登录/改数据。

## 实现原则
- 以参考页面为准，优先还原整体比例、壳层、内容结构、表格密度、主色、主要操作区
- 保留参考系统原有视觉风格，不要擅自"现代化"或改布局/字体/密度
- 用本地 Mock 数据实现交互（搜索/筛选/分页/Tab/下拉/弹窗/行操作），不接真实接口
- 关联页共享同一份 Mock 数据，使跳转/回填/状态可演示
- 只实现参考中可判断且有意义的交互；次要控件给最小反馈

## 执行流程
1. 检查输出目录，建立"参考页面→本地路由"映射
2. 逐页读取 Cursor 浏览器参考页面
3. 输出不超过 3 条实现计划和关键假设，然后实现
4. 完成后本地启动，逐页视觉核对
5. 修复最明显差异（先布局/壳层/结构/密度，后视觉细节）
6. 验证跳转与核心交互

## 完成后输出
1. 已读取的参考页面（标题/URL/视口）→ 本地路由映射
2. 已完成页面、跳转、已实现交互
3. 新增/修改的文件清单
4. 本地启动入口
5. 未实现项、差异、最小假设

## 本次任务信息
- 目标页面：<填写 CMS 页面名或"当前打开的核心页面">
- 输出目录：<本地绝对路径>
- 技术栈：React + TypeScript（Vite）
- 必须保留的交互：<筛选/分页/详情跳转/编辑弹窗等>
```

## 执行纪律

- **先只复刻核心 1-2 页跑通，别一上来梭哈全系统**（课程：复刻多页时 AI 容易每页重新猜一次、风格漂移）。
- 还原后走查"从大到小、从粗到细"：先系统外壳（顶部/侧边栏/内容区比例）→ 再页面结构（筛选/表格/分页/主按钮有没有漏）→ 最后视觉细节。别丢一句"再像一点"，直接指出差异让它只改最明显那处。
- 母版在用户笔记库 `/root/notes/vitamin-course/08 用 AI复刻已有系统前端页面.md`。
