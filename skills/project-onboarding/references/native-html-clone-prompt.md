# 复刻提示词（Cursor 内置浏览器 → 现有工程新增页面 / 或原生 HTML 复刻件）

> 基线：用户自带的「Chrome 多页面复刻提示词」原文，按公司内网 CMS 场景改的六处：浏览器换 Cursor 内置并写死禁用清单、**按产物落点选技术栈**、加「DOM 全量取证（含嵌套控件）」、加「Mock 数据只能来自数据字典」、命名以页面实际显示为准、加红线与分阶段 Checkpoint。
> 用户要求「下次别让我找原文」，直接拿这份发。

## 第一步：先定产物落点，再选模板

| 产物 | 用哪版 | 技术栈 |
|---|---|---|
| 进现有原型工程（新增页面） | 下面的 React 版 | 沿用工程既有栈（如 React + TS + Vite + antd/ProComponents） |
| 独立复刻件（不接构建、不接后端） | 末尾「原生 HTML 变体」 | HTML + CSS + 原生 JS |

**这一步不定就发指令是最常见的翻车点**：照搬来源模板的技术约束（例如「只用原生 HTML、禁 React 与构建工具」）而产物要进 React 工程，两个要求当场对立，做出来的是独立 HTML、进不了原型。发之前先查目标工程的 package.json 与路由组织方式，冲突的节当场改掉，**不要把「这条好像不对」写成结尾的一个问题推给用户**。

```
@Browser <在此粘贴已打开的目标页面链接>

## 一、任务范围
- Cursor 内置浏览器中当前已打开、已登录的 <系统URL与租户> 页面是唯一视觉真源。
- 本次范围：<模块与页面清单>。
- 不设置固定页数上限，每个指定的参考页面对应一个本地业务页面及路由。
- 不因页面中存在菜单、链接或按钮而自行扩展范围。<本次不做的模块显式点名>已有页面不返工。
- 菜单与页面名称一律以页面实际显示为准，不改写、不归一到策划稿叫法。
- 目标页面未在浏览器中打开、无法读取，或未说明页面范围时，不要猜测并开始实现。

## 二、浏览器约束
- 只使用 Cursor 内置浏览器。禁止安装、配置或调用 ego lite、Playwright、Puppeteer 或任何其他浏览器 agent、浏览器插件、自动化库。
- 内置浏览器已登录目标系统，直接在当前标签页操作，不另开窗口，不要求重新登录。
- 内置浏览器不可用时立即停止并告知，不得自行更换方案。

## 三、技术栈与项目约束
- 本次是已有项目，优先遵循现有项目的技术栈、目录结构、路由方案、代码风格和依赖管理方式，不擅自重构或替换现有架构。
- 工程目录：<绝对路径>，技术栈：<栈>。
- 不使用 Tailwind（若工程不用），不引入新的 UI 组件库、状态管理框架或无关工具包，不替换现有组件库，不安装新依赖。
- 不使用 CDN 或外部字体等运行时网络依赖；图标沿用工程现有方案或内联 SVG，禁止用 Emoji 或 Unicode 字符替代图标。
- 禁止将整张参考截图作为背景图、Canvas 或页面图片直接展示。
- 新页面放 <目录>，路由挂在既有路由组内，与同模块已有页面同级；不新建工程，不改 package.json，不动本轮范围外的已有页面。
- 两个及以上页面证实结构一致时才提取共享组件，页面特有布局保留在页面内，避免过度抽象。

## 四、DOM 全量取证（优先级最高）
抓取不许只打开一个控件看一眼。每个筛选区与表单区都要做到：
- 下拉、级联、树选择、穿梭框、多选、日期区间，逐个展开，记录展开后的全部选项文案与 value。
- 控件里还有控件必须逐层展开：级联选择器每一级展开到底，树选择展开到叶子，弹层里再弹出的层也要打开记录，日期控件的自定义起止输入也要记。
- 每个控件记录：所在页面、标签文案、控件类型、默认值、是否必填、选项总数、全部选项原文与 value、选项来源（静态枚举还是接口返回）。
- 展开后看完即收起，不得点「查询」「确定」「应用」这类会改变数据或触发提交的按钮。
- 读不到或展不开的写「未获取」或「未展开」，禁止按常见后台系统的样子补。

## 五、参考页面读取要求
逐页读取并还原：页面标题、最终 URL、当前视口尺寸；整体布局与导航层级；文字、字体、颜色、尺寸、间距、边框、阴影与信息密度；表格、表单、Tab、分页、弹窗、状态与可见操作；页面之间已观察到的安全跳转关系。
只允许浏览观察所需的安全操作。不得执行保存、提交、删除、导出、退出登录、切换账号或其他会改变真实系统数据的操作。

## 六、视觉还原原则
- 以参考页面为准，优先还原整体比例、壳层尺寸、内容结构、表格或表单密度、主色和主要操作区。
- 尽可能还原真实页面的文字内容、字段名称、表格列、操作按钮及数据展示形式。
- 保留参考系统原有的固定宽度、横向滚动、控件密度和视觉风格，不擅自「现代化」改造。
- 优先适配参考页面当前视口，不凭空增加移动端或响应式设计；宽表格在自身容器内横向滚动。

## 七、交互与 Mock 数据
- 不接入真实业务接口，使用本地状态和少量 Mock 数据模拟交互；列表、详情、编辑等关联页共享同一份 Mock 数据。
- 表单按参考页面还原必填校验、错误提示、禁用状态、操作反馈等可观察到的行为。
- 只实现参考中能判断且有意义的交互；无法确认的次要控件给最小反馈，不自行补全复杂业务流程。
- Mock 硬约束：数据只能来自页面真实值 + 落盘的数据字典；枚举必须来自抓到的选项清单，不许发明；字段名、列名、状态文案照抄原文；日期格式、金额进位、脱敏形态与真实页一致；字典里没有的字段不许上页面；工程已有主数据层或种子数据时从那里引用，不写死字面量。

## 八、执行流程
1. 检查工程与技术栈、目录、路由、现有 mock 与主数据组织方式，建立「参考页面 → 本地组件/路由」映射。
2. 逐页取证，先完成第四节并把字段与枚举写进数据字典。
3. 输出不超过 3 条实现计划和关键假设，然后直接实现。
4. 启动本地项目，在与参考页相同的 CSS 视口下逐页对比渲染效果，优先修布局比例、壳层、内容结构、信息密度、颜色与关键操作区。
5. 不以代码写完作为结束标准，必须检查实际渲染结果：文字溢出、遮挡、控制台报错、路由刷新与核心交互。

## 九、红线禁止
- 只使用 Cursor 内置浏览器，禁用任何其他浏览器 agent 或自动化工具。
- 全程只读目标系统：不得保存、提交、发布、删除、启用、停用、导出，不得进入新建流程填数据，不得修改已有记录。
- 不得执行任何 git 操作。
- 不新建工程、不装依赖、不改 package.json、不引入工程未用的样式方案、不动范围外的已有页面。
- 不得猜测补全，不得自行扩展页面范围，不得改写页面原文文案。
- 不得只抓首屏下结论，列表要翻页确认列结构与总条数。
- 遇到登录墙、权限不足、租户不对，立即停止并告知。

## 十、完成后输出
1. 页面映射：参考页面标题、URL、视口 → 本地组件/路由。
2. 实现结果：已完成页面、页面间跳转、核心交互。
3. 文件变更清单与运行方式。
4. 遗留问题：未实现项、仍有差异、采用的最小假设。
5. 数据字典产出：枚举控件清单（控件→选项→value）与字段 TSV 的路径与条目数。
```

## 原生 HTML 变体（独立复刻件）

React 版只换「三、技术栈与项目约束」与「十、完成后输出」两节，其余各节原样保留：

- 多页时入口 `index.html`，其余按页面语义命名独立 `.html`；允许少量共享 `assets/styles.css`、`assets/common.js`、SVG/PNG。
- 只用 HTML + CSS + 原生 JS；不使用 React/Vue/Tailwind/npm 包/CDN/外部字体/构建工具；页面双击可开，不依赖网络与本地服务。
- 页面跳转用本地 `a` 或原生 JS，且跳转关系必须对应参考中已观察到的真实关系。

## 沉淀到数据字典的落点约定

字段与枚举一律先产出为「候选」TSV，落到复刻产物目录；验收后再合并进项目正式的字段清单详细稿，不直接改正式文件。

## 两个配套坑

1. **只写「用 Cursor 内置浏览器」不够**，必须同时给禁用清单（ego lite / Playwright / Puppeteer / 浏览器插件），否则 agent 会去装替代品，一轮时间全花在配环境上。
2. **参考页在跨域 iframe 里时**（CMS 壳页嵌商城后台这类），外层页面 DOM 读不到表格：在同一会话里直接打开 iframe 的真实 URL 取证，并让复刻件把「这是嵌入的外部系统」这一形态做出来（独立容器 + 边界 + 容器内独立滚动），不要做成 CMS 原生页面。
