# Windows 桌面用户适配（Mac→公司 Windows + 视障敏感）

用户（路飞）刚从 M1 Max MacBook（Retina）切到公司 Windows 台式/商务本，且**视障**——屏幕清晰度直接影响他的眼睛疲劳程度，这是第一优先级的体验问题，不是"将就"问题。处理这类求助时：先共情接住难受，再给能立刻缓解的实操，别只说理论。

## 核心认知：清晰度看 PPI，不是分辨率数字
- 用户主观"分辨率差/看不清"≠分辨率被调低了。先看 PPI（每英寸像素数）：
  - Mac 16寸 M1 Max = 3456×2234，~254 PPI（Retina）
  - 公司 13寸 1920×1200 商务本 = ~174 PPI
  - 24/28寸 1080p 外接 = ~92/78 PPI（大但颗粒感重）
- 像素密度差距 1.5 倍以上，同一文字的锐利度天壤之别。从 Retina 切到低 PPI 屏，眼睛要拼命对焦，累是生理反应，不是矫情。
- macOS 是高密度平滑渲染（适合 Retina）；Windows 用 ClearType 亚像素渲染，低分屏上先天更糊、有彩边。

## 排查步骤
1. 先区分是"分辨率被调低"还是"本来 PPI 低"：看 DxDiag 的 Current Mode 是否等于 Native Mode。
2. DxDiag 读显示器信息用 grep：`Current Mode:` / `Native Mode:` / `Monitor Model:` / `System Manufacturer:` / `System Model:` —— 一次列出所有显示器（笔记本内屏 + 外接 + Citrix 虚拟屏）。
3. 判断是否多屏 DPI 不一致（笔记本 150%、外接 100%）→ 跨屏拖窗口会发虚，这是"看久了费眼"的常见隐藏原因。

## 缓解操作（按性价比排）
- **统一缩放**：设置→系统→显示→把所有屏缩放调到一致（125%/150%），治跨屏发虚。
- **单独放大字体**：设置→辅助功能→文本大小，调 +2~+4 档，不动布局只放大文字，对视障最管用。
- **ClearType 调优**：设置→个性化→字体→调整 ClearType 文本，跟着向导走一遍改善发虚。
- **夜间模式**：设置→系统→屏幕→夜间模式，傍晚转暖黄光，护眼。
- **显示器放远 + 亮度别拉满**：低 PPI 屏离远看颗粒感不明显。
- 换屏后：缩放调到位 → 设为主显示器 → `Win+P` 选"仅第二屏幕"关掉笔记本屏（少扭头）。

## 显示器选型（帮用户申请时）
- **27寸 2K（2560×1440）是桌面甜点位**：尺寸+密度平衡最好，最推荐。
- 27寸 4K 更顶（Windows 要调 150% 缩放）。
- 27/28寸 1080p = 大但不锐，颗粒感明显。
- 公司采购逻辑是**成本 + 统一标准**，不会按岗位需求配好屏。用户要主动跟领导/IT 提，**用业务理由**："我审高保真原型和做 UI 细节检查，需要 2K 看像素对齐"——产品岗这个理由正当，能提高申请成功率。

## 公司 Windows 机器现实
- 新到岗（尤其头两周）：先摸 IT 政策，别冒险装东西/连个人服务。
- 公司配的 AI 工具（如 M365 Copilot）是**公司租户，管理员有审计权限**——只装工作内容，绝不碰个人私密；工作/个人账号严格分开。
- 机器型号核实：DxDiag 的 System Manufacturer/Model 为准，别假设品牌（曾以为联想台式，实际是 HP EliteBook）。
- **性能看后缀，别被型号唬住**（0831 实测 HP EliteBook 830 G11）：`Intel Ultra 7 155U` 的 **U = 低功耗轻薄本芯片**，基础频率才 1.7GHz，多任务一满就卡——\"Ultra/i7\" 只是命名好听，不是性能本。开几个 AI 工具 + 网页就卡，根因是**低压 CPU + 仅 16GB 内存 + 只有核显（无独显）+ 商务本散热弱**。
  - **预期管理**：这台是\"轻办公机\"，干公司活（接需求/写文档/用公司 agent/看 CMS）够用，但别指望跑重型 AI。就算以后申请到苹果本，**16GB 也不够用户的重型 AI 工作流**（本地模型/多开/大上下文，32GB 起步 64GB 才舒服）。
  - **给用户的务实建议**：别同时开太多 AI 工具（用哪个开哪个）、网页标签别攒几十个（内存硬伤）。重型 AI 工作永远在自己 Mac/VPS 上，公司机只做轻办公——这是干净边界，不是妥协。

## 公司 IT 边界决策框架（0831 定稿）
这是帮用户判断"公司机器上能不能做 X"的核心模型——**不是所有网络请求都危险，公司数据安全的核心是防"输出"而非"输入"**：

- **公司严防"输出"**：把公司内部数据/代码/资料传出去 → 红线，绝不碰。
- **公司宽容"输入"**：从外部拉公开竞品/行业信息做调研 → 一般不管，放心做（用户原话"主要把控好输出，输入随便"）。
- **物理隔离铁律**：vivo 禁止自带电脑进公司 → 用户私人 AI 工作流（罗宾/Codex/切号/采集）天然只在自己设备(家里 Mac/VPS)上，公司电脑根本碰不到，这是最干净的边界，无需刻意规避。
- **VPS 调研基地模式**（绕开公司采集限制的正规做法）：
  1. 竞品/外部数据采集在**自己的 VPS 上**做，且用**自己设备(手机/家里)**触发配置，别在公司电脑 SSH 进 VPS 跑采集（换壳仍是"公司电脑在采集"）。
  2. 成果整理成中性"调研报告"（非原始采集包）放 VPS 下载页。
  3. 公司电脑只做"访问 VPS 下载干净报告"这一步。
  4. 只抓公开/正常页面，别碰需登录/绕反爬/私密数据，避免触发对方反爬或公司告警。
- **私人内容三条线**：私人 Obsidian 笔记只手机看（蜂窝流量）不进公司电脑；私人 AI 账号/凭证别在公司电脑登录；私密/规划话题用手机聊，公司电脑只聊工作。obsidian 客户端装了就直接卸载，别留痕。
- **公司允许外部 AI agent**（vivo 明确允许 Codex/Cursor，另有自家类 WorkBuddy agent 已申请）——但用公司的干公司活，私人武器守着自己。公司允许用 agent ≠ 不监控，访问域名/登录账号 IT 仍可见。

## 外设：鼠标 / 罗技 Options+ 装不上怎么办

用户会把自己手感好的鼠标带到公司机用（MX Master 3S 这类多设备鼠标）。装驱动这一步容易卡，因为罗技现在的下载链路是「下载器 + 在线拉组件」，不是一键安装包。

**装什么**：只装 **Logi Options+**（带加号）。老版 Logitech Options 不认 3S，Logitech G HUB 是游戏外设专用，都不要装。

**三条常见的“打不开”**，按顺序查：

1. **装的是下载器不是本体**：官网现在只给 `Logi Download Assistant`，装完它没有主界面，只是等你选要装哪个软件。要去开始菜单打开它、在里面继续选 Options+ 下载。官网已无独立离线完整包，别承诺“去下离线包”。
2. **卡在“重新启动电脑以继续”**：提示意思是先装 Microsoft VC++ 可再发行组件、装完重启，**重启后必须自己再运行一次安装程序**才会接着装，重启不会自动续装。反复弹同一提示就是 VC++ 没装上，直接给微软直链 `https://aka.ms/vs/17/release/vc_redist.x64.exe` 装上再重跑安装程序。
3. **卡在“选择连接类型 → 蓝牙”，点进去打开系统蓝牙面板什么都没**：这个向导是给**添加新设备**用的。设备早就连上了就等于没有“可配对的设备”，必然卡死。退回主界面看设备卡片在不在——在就说明装好了。

**多设备鼠标的通道坑**：3S 底部有 1/2/3 三个 Easy-Switch 通道，各连一台设备。它可能停在别的设备的通道上，Windows 这边就搜不到。按一下切换键看哪个灯亮，选空闲通道长按 3 秒到灯快闪进配对模式，再去系统蓝牙里搜。不想折腾就插 USB 接收器。

**装好之后值得设的**（给用户时带 ☐ 勾选框）：指针速度中偏快（指针加速别关，关了发飘）；滚轮开 SmartShift 自动切自由滚动；拇指轮设横向滚动、按下设音量；侧键保留前进后退；**中键保留别改**（很多软件靠它在标签页开链接和粘贴）；手势四向设 任务视图 / 显示桌面 / 后退 / 前进；只一台机用就把 Flow 关掉（它扫局域网、费电还偶尔卡）；开低电量提示。「应用程序特定设置」等用一周发现哪个软件不顺再单独配。

## Mac 有、Windows 没有：别把 Mac 的手势/桌面习惯照搬过来

用户会下意识拿 Mac 体验做标尺，遇到“跟 Mac 不一样”时先分清是软件没做好还是系统本来不同——**这几件是 Windows 做不到，不是罗技/配置问题**：

- **虚拟桌面是全局的**：Windows 一切换虚拟桌面，主屏副屏一起切（虚拟桌面本身就是全局一套）。Mac 默认每个显示器可以是独立空间。所以“用鼠标手势切桌面”在多屏下体验很差，别推荐；改把左右手势设成滚到页面顶部/底部，或音量加减，虚拟桌面留给 `Win+Ctrl+←/→` 手动按。
- **手势可选项比 Mac 少**：Windows 版 Options+ 的四向动作基本只有 任务视图 / 显示桌面 / 截屏 / 全屏截图 / 切虚拟桌面，没有 Mac 的调度中心、启动台、媒体控制。要更细的动作只能靠自定义快捷键，不是所有需求都能满足。
- 对照关系可直接告诉用户：调度中心→任务视图、启动台→开始菜单、三指左右→切虚拟桌面（但见上面多屏的坑）。

## 屏幕上反复弹 Num Lock 提示怎么查

隔一会儿冒一次「Num Lock 开/关」的 OSD，且**笔记本上 Num Lock 会改变 U/I/O/J/K/L 那组键的字符**，输密码、写代码会莫名其妙出错，别放着不管。

**先问一句键盘���没有小键盘区（75% 及以下配列没有）**，这决定你要修的是两件事里的哪一件：没有小键盘区时 Num Lock 开关对输入毫无影响，用户要的只是“别弹提示”，排查目标直接定在“关掉那个 OSD”，别往字符输出上绕；有数字键区时才是真问题，锁定状态一错就输不进去。用户可能自己先说出“对我没影响但很烦”——这就是在告诉你按后一种目标办。

按这个顺序查，**第 1 步最关键，走错方向会白排查一圈硬件**：

1. **先分清「状态真变了」还是「提示框误弹」**，两个判据叠着用：
   - **屏幕键盘看灯（最快最准）**：`Win+R` 输 `osk` 打开屏幕键盘，盯着 Num Lock / Caps Lock / Scroll Lock 三个键——提示框弹出的瞬间，屏幕上那个键有没有跟着亮灭。**跟着变＝真有按键在发；不跟着变＝纯误报**。这比记事本测试直观，能同时看多个锁定键。
   - **记事本看输出**：连按 U I O J K L——出数字＝Num Lock 真开着，出字母/光标动＝关着。等提示再弹时立刻重按，输出没变＝误报。
2. **误报 → 先查联想热键服务**：`TPHKLOAD`（Lenovo Hotkey Client Loader）会自己误触发 OSD。管理员 PowerShell 跑 `Stop-Service -Name TPHKLOAD -Force` + `Set-Service -Name TPHKLOAD -StartupType Disabled`（可逆：改回 `Automatic` 再重启）。代价是 Fn 调亮度/音量的提示条会消失，功能本身还在。
3. **真的在变 → 再分鼠标还是键盘**：鼠标底部开关拨到关（或拔接收器）等几分钟。不弹＝鼠标某键/手势被映射成 Num Lock，去 Options+ 逐个可点位置查；还弹＝键盘或后台程序，见下一节。
4. **联想服务停了还弹、甚至从 Num Lock 扩到 Scroll Lock / Caps Lock 都弹 → 查外设软件的后台钩子**。鼠标/键盘厂商的驱动会 hook 输入层，触发系统或 OEM 的锁定键状态通知，造成一片锁定键集体误报。验证方法：管理员 PowerShell 跑 `Stop-Service -Name OptionsPlusUpdaterService -Force`，再 `Get-Process | Where-Object { $_.ProcessName -match "logi" } | Stop-Process -Force`（托盘图标消失属正常），正常用十几分钟看还弹不弹。
   - 判定后怎么处置：3S 的多设备切换和滚轮模式切换是**硬件级**的，卸掉 Options+ 鼠标照常能用，丢的只是手势/侧键自定义/电量显示——按用户对这些功能的实际依赖程度权衡，不必为了保功能硬留一个有冲突的驱动。
   - 查是哪个组件时用 `Get-Service | Where-Object { $_.Name -match "logi" -or $_.DisplayName -match "Logi" }` 看服务，`Get-Process | Where-Object { $_.ProcessName -match "logi" }` 看进程，两条都要看——服务在跑不代表**界面没开就没事**，装完就一直常驻。

**定位到具体哪个组件：逐个 kill 二分，别一次全杀（2026-11-03 MX Master 3S 实测）**

一次把 logi 进程全杀掉，等于同时放弃了手势，得不出“能不能既保手势又去提示”的结论。正确做法是一次只杀一个，每杀一个测两件事：**手势还灵不灵、提示还弹不弹**。

- 用 `taskkill /F /IM <进程名>.exe`，**不要写带 `$` 变量的 PowerShell 循环**——聊天平台会把 `$` 吞掉、把 `_` 转义成 `\_`，用户复制过去直接语法报错。
- 实测结论（MX Master 3S + Options+）：
  - `logioptionsplus_logivoice`（语音/AI 组件）**不是元凶**，杀了手势照旧、提示照弹。
  - **`logioptionsplus_appbroker` 是元凶**：杀掉它后手势完全正常、锁键提示不再弹。它负责应用集成钩子，与鼠标手势无关。
  - `logioptionsplus_agent` **不能杀**——手势靠它，杀了手势就废。
- 所以“要手势就得忍提示”不成立，去掉 appbroker 就能两全。
- 固化办法：做成开机计划任务/启动脚本在罗技启动后延迟几十秒杀一次 appbroker（它可能被主进程重新拉起，先 `tasklist | findstr appbroker` 验一下会不会自己回来）；更彻底是把 appbroker.exe 改名或删掉，代价是软件升级可能恢复、部分应用集成功能失效。
  - **实测补充：杀一次就够的情况很常见，别急着上持久化**。进程虽被主进程重新拉起（`tasklist` 能看到新 PID），但内部状态已被重置、提示不再复现。先让用户正常用一天；只有“重启后又开始误报”才值得做计划任务或改名。
- 另一条要告诉用户的边界：**手势依赖软件后台常驻**。配置虽写进鼠标板载内存（在 Mac 配好，Windows 端不用重配），但 Windows 上进程不在跑，手势依然不生效——“Mac 配好带过来就不用装软件”是错的。

排查时用户常已经试过重启、关鼠标、停服务仍不消失——此时别再往「哪个软件在按」上钻，直接看下一节的键盘模式。**注意：键盘在 Mac 模式下做的所有按键测试结论都不可信**（键位被整体重映射），先把键盘切回 Win 档再重测一遍。

## 键盘快捷键集体失灵 = 先查键盘是不是在 Mac 模式

以下三个症状**同时出现**时，基本可以判定键盘处在 Mac 模式，不是驱动坏了、不是系统故障：

- Alt+Tab 不直接切上一个应用，只弹出切换器停在原地
- Win+Shift+S 之类截屏快捷键失效
- Num Lock 提示反复弹（Mac 模式下这个键本来就不存在）

机制：Mac 模式下物理键位被重映射（Alt 位置变 Command、Win 键不存在），所有 Win 组合键和部分 Alt 组合键自然失效。此时无论怎么改多任务设置、停热键服务、重启都没用。

**动作**：让用户看键盘侧面或背面找 Mac/Win 切换开关（标 ⌘/⊞ 或 Mac/Win），拨到 Win 一档；没有物理开关就试 `Fn+W`。**先问清他现在到底插着哪把键盘**——如果是笔记本内置键盘，这条路不成立，要换方向查。

顺带一条排除项：Alt+Tab 只弹切换器也可能是「多任务 → Alt+Tab 显示 N 个最新选项卡」这个设置项（改成「不显示选项卡」即可），但**它解释不了截屏快捷键同时失效**，两个症状一起出现就别往设置项上查。

## 给用户 PowerShell 命令时的两个硬性要求

- **不用 `-like "*logi*"` 这类通配符**：聊天平台会把 `*` 当格式符号吞掉，用户复制过去变成 `-like "logi"`，精确匹配不到任何东西，却返回空列表让人误判成「没有这个进程」。改成 `-match "logi"`（正则、不受星号影响）或 `$_.ProcessName.Contains(...)`。
- **引号必须是英文引号**：中文引号 `“ ”` 在 PowerShell 里不是合法引号，命令行为会变得不对但不报错。发出去时确认是 `"`。
- 每条命令配一句「返回什么代表什么」，让用户不用懂也能判断结果——他是视障用户，靠读文字输出判断状态。

## 沟通风格
- 用户新环境第一天情绪容易崩（眼睛难受、Windows 不习惯），先接住再说方案。
- 给可复制粘贴的具体操作路径，别让他猜。手机/飞书端用简短清单，别发长文。
