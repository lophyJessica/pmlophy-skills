# 多语言导入文件合并

场景：版本上线前要在多语言系统里配多语言。手上两份表——平台导出的全量键值表、在线文档里本次翻译的内容——要合成一份可导入文件。

## 两份输入，角色不同

| 输入 | 是什么 | 角色 |
|---|---|---|
| **A 平台导出表**（单 sheet，如 `download.xls` / sheet `data`） | 从多语言平台导出的全量现有键值（含所有语种列、`remark`、`label`） | **导入文件的骨架**：列顺序、表头、行序全照它 |
| **B 在线翻译文档**（如 vivo 文档某 sheet） | 本次新增 key + 原有 key 的缺失语种译文 | **只提供译文数据**，不决定结构 |

典型规模参考：A 17 列（`config_key / remark / label / zh_CN / en_US / zh_HK / zh_TW / my_MM / th_TH / in_ID / vi_VN / ar_EG / en_MY / en_PH / en_BD / id_ID / kh_KH`）× 359 条；B 9 列（`config_key / zh_CN / en_MY / en_BD / en_PH / in_ID / zh_TW / vi_VN / th_TH`）× 164 条。

## 流程：两步，中间必须 Checkpoint

**第一步：只核结构，不出文件**

1. 读 A：sheet 名、表头原文逐列、行数、唯一 key 数（`config_key` 非空且无重复）。
2. 读 B：列名原文 + **全部**数据行。
3. 报三个数：**key 交集 / 新增（B 有 A 无）/ 缺失（A 有 B 无）**。没拿到 B 的全量前**不许给这三个数**——抽样推算出来的交集数是编的，第二步会被推翻。
4. 另报一份「**疑似同一个 key 但写法不同**」清单（单复数 `guide.` vs `guides.`、大小写、多空格），**只列不改**。

**第二步：合并 + 自检报告**

## 合并规则（缺一条就导入报错或数据被覆盖）

- **以 A 的结构为准**：列顺序、列名、行序、尾部列都不动；**不删列、不改列名、不排序**；原有行保持原序，新增行追加到末尾。
- **精确匹配 `config_key`**（比较前 trim 首尾空格）。不模糊匹配、不按相似度——`guide.` 与 `guides.` 是两个不同的 key。
- **只填空缺，绝不覆盖**：A 中该语种单元格为空才填；A 已有非空译文一律不动，**哪怕 B 给了不同译文**——后者只进「冲突清单」交人判。
- **新增 key 追加新行**：填 B 提供的 `zh_CN` 与各语种；`remark` / `label` 先留空（除非用户另说）。
- **产物另存新文件**，不改动 A 原文件；输出格式与 A 一致（A 是 `.xls` 就出 `.xls`）。
- **自检报告**至少含：新增 key 数、追加行数、各语种填补的单元格数（逐语种）、冲突清单（位置 + A 现值 + B 值）、最终行数与列数是否与 A 完全一致。

## 语言代码陷阱（每轮都要重新对）

- **平台可能同时存在两个含义相近的列**：如 `in_ID`（旧/非标准印尼语码）与 `id_ID`（ISO 印尼语）。配置中心的语言映射是 `id → id_ID`，而在线文档常写「印尼语 in_ID」——两边对不上时，**一次把两列都填上**（用户口径：双保险，别猜），并把这条写进自检报告。
- 在线文档的表头常把地区与语言混写（「马来（英语 en_MY）」「孟加拉（英语 en_BD）」）：**以括号里的语言/地区码为准去映射**，不要按国家名猜。
- A 有、B 没有的语种（如 `en_US / zh_HK / my_MM / ar_EG / kh_KH`）**一律不动**——本次没翻就是没有，不要用别的语种顶替，也不要清空。

## 拿 B 的机器可读副本（最容易卡住的一步）

公司在线文档（WPS 内核）是 **canvas 渲染**：读不到 DOM 表格，`Ctrl+A` / `Ctrl+C` 也常常接不到系统剪贴板，逐格 OCR 几百行×多列必然出错。**不要在 canvas 上硬抓**，直接要本地文件：

1. 让用户在文档里**下载/导出该 sheet** 为 `.xlsx`，把**路径**给 agent；或
2. 让用户选中整块（如 `A1:I165`）→ 复制 → 粘到本地新建 Excel 保存 → 给路径。

行数以 **`Ctrl+End` 的实测为准**（名称框能跳到的最后有数据单元格是 `A165` 就是 165 行），**不要用滚动时看到的行号估**；做不到逐行抓取就如实说，不要用抽样数据往下算。

## 交付话术

第一步报告**明确写「未生成任何文件」**，把两个待确认点一次问清（行数认不认、B 的本地路径何时给），别一边合并一边补数据；同时确认一个口径：A 本机打开时右侧多出来的空白列**不算列**，导入文件表头以 A 文件实际列数为准。
