# WMS 生成模式 — 主PRD + Demo规格嵌指令

WMS 比进销存 ERP 复杂——入出库有多步骤工作流（收货→质检→上架→回写；波次→拣货→播种→复核→包装→交运）。每步都要 Demo 页。

## 模式

1. **主 PRD 独立文件** — 只写核心逻辑：状态机、业务规则、单据体系。不写 UI 细节。
2. **Demo 规格嵌在五段曲指令里** — 列表页列定义/表单字段/交互/强控拦截/Mock数量全写在 Request 段。
3. **一条指令跑多个模块** — 入库(4页)+出库(7页)+库存(2页)=13页，一条五段曲指令搞定。

## 为什么不用独立 Demo PRD 文件

- 节省文件数：WMS 6 模块如果每个都出独立 Demo PRD，多写 12+ 个文件
- 规格嵌指令跟独立文件效果一样——反重力编译通过率不变
- 后续如需复用，从指令里反向提取 Demo PRD 即可

## 实战结果

WMS 第一批（入库+出库+库存）13 个页面，一条指令零返工，npm run build 一次通过。
