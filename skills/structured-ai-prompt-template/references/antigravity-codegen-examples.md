# 反重力代码生成实战案例

> 2026-07-05，强盛科技进销存项目，7轮指令全部编译通过，零返工。

## 成功要素

1. Context 段写死：项目路径、参照物文件、PRD 路径全部绝对路径
2. Constraints 段列红线：不脑补审核流、不自行加字段、不加导入按钮
3. Request 段分条列：文件清单 + 页面结构 + 路由 + Mock 要求
4. Checkpoint 段设卡：npm run build 通过再汇报

## 关键技巧

- 参照物策略：每条指令开头写"参照物：已有的 XX 页面"，反重力主动对齐代码风格
- 状态机显式化：单据类指令必须写清状态枚举值，防止 AI 脑补审核流
- Mock 数据要求：每条指令写清最少条数和状态覆盖
- 禁止项前置：Constraints 段用"不要X"句式，比"请做Y"更能防跑偏
- 导入按钮陷阱：AI 习惯性加导入功能，必须在 Constraints 明确禁止（一期 Out of Scope）
