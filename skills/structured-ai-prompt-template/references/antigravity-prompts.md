# Antigravity 前端生成已验证提示词模板

> 以下模板在强盛科技进销存项目中 6 轮验证，npm run build 全部通过。

## 业务单据类（3 页：列表+表单+详情）

参照物：已有 PO/PI 模块的完整代码。执行层单据状态机简化（草稿/已确认/已作废，无审核流）。

### Context 模板
```
项目+用途。项目路径：绝对路径。
参照物：已有页面（文件名+路径）。
PRD：规格文档路径。
关键技术差异：与参照物不同的核心逻辑（如三数量口径、下推创建、字段继承）
```

### Constraints 模板
```
- 不加审核流（执行层单据仅草稿/已确认/已作废）
- 不加"新增"按钮（工具条，必须从上游下推）
- 上游字段全部只读不可修改
- 状态配色严格按PRD：草稿=灰/已确认=绿/已作废=红
- 不渲染disabled按钮（不满足条件直接隐藏）
- 不加导入功能（一期Out of Scope）
```

## 查询页类（1 页：纯列表）

无状态机、无CRUD、无Tab。参照物：FL/即时库存列表页。

### 关键Constraints差异
```
- 不加Tab栏
- 不加新增/编辑/删除按钮
- 不加状态列
- 不加勾选列（只读查询不支持批量操作）
- 不加二次确认弹窗
```

## Checkpoint 统一格式
```
全部N个文件+types+api完成后，npm run build 通过汇报结果。
编译报错就停下来，不要强行继续。
```
