## 命名演进

```
Constraints → 红线禁止（不限数量，按类举例）
三个不要   → 三原则（指令层/文件层/人脑层）
两依赖五段曲 → 两依赖 + 五部曲 + 三原则
```

## 核心洞察

1. **审查前置**：多线程场景下人没有时间逐行审查，质量不靠事后纠错，靠指令里锁死
2. **文件隔离**：并行第一原则，不同 Agent 必须操作物理独立的文件
3. **人脑瓶颈**：多 Agent 并行时瓶颈不在 AI，在人脑上下文切换成本
4. **AI 不淘汰 PM**：淘汰的是只会输入一句话等结果的人
