# 系统图绘制与验收（时序图 / 业务流程图 → PNG）

用于「给我系统流程图（时序图）+ 业务流程图，详细的」。产物是两张 PNG 长图，源 HTML 留档以便下轮改。

## 一 拆分与骨架

两个 HTML 各出一张图：`seq.html`（系统时序图）、`flow.html`（业务流程图）。

两图都要：顶部 `<h1>` 写清图叫什么、`.sub` 一句说明依据（源码实证 / 谁提供），底部 `.anno` 黄底「看图要点」编号列出结论，`.src` 小灰字写证据位置与**没核验的边界**（表名是默认值、生产未核验之类）。

## 二 时序图（JS 驱动渲染）

参与方 6 列以内最稳。容器宽 1380，列心 `x(i) = 130 + i*232`。

```
参与方头部：position absolute, width 168, margin-left -84（居中于列心）
生命线：width 1px，从头部底(top 62) 画到最后一行
```

三种行，各自占高：

| 行 | 数据形状 | 占高 |
|---|---|---|
| 阶段标题 | `{t:'grp', x}` | 50 |
| 消息 | `{t:'msg', f, to, l, d?}`（`d:1` = 虚线/返回） | 48 |
| 注释框 | `{t:'note', at, ox, w, s}`（挂某列、可左右偏移） | 62 |

渲染坐标：箭线 `top = y+20`，三角 `top = y+15`（`border-top/bottom 5px transparent` 居中于线），文字 `top = y`、`left = 两端中点`、白底 `padding 0 7px` 压线显示。

规则：

- **同一参与方内部的处理不要画折返箭头**，用 `note` 表达（“BFF 内部：按 eventId 重查配置补表名”）。
- 阶段分组用 `grp` 行把一条链路圈起来（A 保存 / B 使用 / C 固化），不要用背景色块横跨整图。
- 注释框文字控制在两行内（宽 470–500、字号 10.5 每行约 41 字），超了会被下一行压住。
- 图里有“未取证”的地方就用注释框写出来（“无源码证据”“仓库外机制未核验”），不要省略。

## 三 业务流程图（竖向节点数组）

```
{t:'stage', c:'o|g|p|', x}           阶段色块（o=橙=外部依赖 / 蓝=配置 / g=绿=使用 / p=紫=固化）
{t:'node', k:'act|sys|data|dec|ext|end', n:'编号', x:'标题', d:'说明'}   节点
{t:'conn'}                            竖连接线（26px）
{t:'branch', left:{lab,k,n,x,d}, right:{...}}   判断分叉，左右两盒
```

- 节点左边框色条区分角色：蓝=业务动作、灰=系统处理、紫=数据侧、橙虚线=外部依赖/判断、绿=终结产出。
- `d` 里写**坑或待确认**（“左闭右开，选到今天会漏一天”“缓存 8 小时内不复算”），不要另开段落叙述。
- 底部单独一块橙色虚线「待确认」：每条写清**卡在哪**（谁维护、谁生产、谁拍），不写“暂无数据”。
- 目标 18 步左右，超过 25 步拆两张。

## 四 截图与裁剪

```
systemd-run --scope -p MemoryMax=700M -p MemorySwapMax=0 --unit=shot-$$ <chrome> \
  --headless=new --no-sandbox --disable-gpu --hide-scrollbars \
  --force-device-scale-factor=2 --window-size=<内容宽+120>,<给足> \
  --screenshot=/abs/out.png file:///abs/x.html
```

- 竖向流程图内容宽约等于 frame 宽（本例 1060 → 窗口 1130）；窗口比内容窄 = 右列被裁。
- 高度给足：时序图 30+ 行约 2900，竖向流程图 18 步约 4200。
- 裁底部白边：`python3 scripts/trim_bottom_whitespace.py out.png`；**底部留白 < 40px 说明内容被切**，调高窗口重截，不要直接发。
- stderr 的 dbus / UPower / GLib 报错无害。

## 五 校验（两步，缺一步会发出错图）

1. **整图问四点**：`vision_analyze` 问「列头是否重叠 / 箭头与标签是否互压 / 左右与底部是否裁掉文字 / 有无异常空白」。
2. **局部放大再问一次**：`region=[0, 中段y, 宽, 下段y]` 只问“标签有没有叠字、有没有超出边界”。整图问一次模型一律答“排版良好”，局部错位看不出来。

必要时补 DOM 断言：`js()` 数方框/箭头数量，和 rows 数组条数对一遍。

## 六 坑

- 中文字体必须写 `WenQuanYi Micro Hei`（VPS 上只有文泉驿），否则出方块。
- 想省事把两张图塞一个 HTML：长图超窗口、底图被切，读者也分不清系统图与业务图。
- 表名/表结构可以上图，但要标「代码默认值、可被配置覆盖、生产未核验」；不标就是拿推断当事实。
- 一条消息的文字过长会横向跨两三列——宁可拆两行小字（中文在上、接口名在下），也不要压住相邻列的箭头。
