# Windows 工作机上手与视障屏幕适配

适用：用户(路飞，视障)拿到公司 Windows 工作机、抱怨"眼睛要瞎了/分辨率太差/字太小/屏幕发糊"、或刚换平台(如 Mac→Windows)不适应时。目标不是改造用户，而是用系统设置+工具让机器迁就他的眼睛。

## 核心原则(先接情绪，再给方案)
- 用户平台切换初期的不适应是**情绪问题在先**。先共情("Windows 和 Mac 是两个世界，从 M1 Max 切到公司机第一天不习惯太正常了")，再动手。用户明确"不用了，就用Windows吧"时，**停止推销改造方案**，尊重他的决定，只在他主动问时给。
- 区分两块难受："操作习惯没了"(快捷键/窗口/搜索) vs "我的东西断了"(AI 工作流、顺手工具在公司机全得重来)。对症给，别一股脑堆方案。
- 视障用户优先**单点放大文字**(辅助功能→文本大小)而非整体缩放，更护眼且不破坏布局。见下方"屏幕适配"。

## 查 Windows 硬件型号(用户可自助)
1. `Win+R` → 输入 `dxdiag` → 回车。看"系统制造商 / 系统型号"两行。
2. 或 `开始` → 设置(齿轮) → 系统 → 关于 → 最底部"设备规格"。
3. 用户也可直接把 DxDiag 导出文本发来(Hermes 直接读文件分析，见下节)。

## 用 DxDiag.txt 读机器(本助手执行)
用户发来 DxDiag 文本时，重点 grep 这几项判断问题：
- `System Manufacturer` / `System Model` → 品牌机型
- `Processor` / `Memory` → 算力
- **显示段**：`Current Mode`(分辨率) / `System DPI Setting`(缩放百分比) / `Monitor Model`(外接屏型号) / `Display Topology: Extend`(多屏扩展) / `Native Mode`(面板原生分辨率)

**关键判读**：所有屏 Current Mode == Native Mode 且 DPI 已 150% → 分辨率没问题，"费眼"真因是**混合 DPI 发虚**(笔记本 150% + 外接屏 100%，拖窗口跨屏就糊)或**13寸小屏字仍偏小**，不是像素不够。别误判为"分辨率太低"。

## 屏幕适配三步(视障护眼，极简单，按序给)
1. **统一缩放治发虚**：设置→系统→显示→点外接屏，把"缩放"调到与笔记本一致(如都 150%)。混 DPI 拖窗口发糊的根因。
2. **单点放大文字(最护眼)**：设置→辅助功能→文本大小→滑块调大(+2~+4 档)。单独放大文字，不动布局清晰度，比整体缩放更护眼，专为视障设计。
3. **夜间模式护眼**：设置→系统→屏幕→夜间模式，傍晚自动变暖黄光，晚上少刺眼。

## 找回 Mac 手感的 Windows 工具(仅当用户要"尽量像 Mac"时给)
- **Everything**：秒级全盘搜索，替代 Spotlight
- **PowerToys**(微软官方免费)：FancyZones 自定义窗口分屏、快捷键自定义
- **Wox / Flow Launcher**：类 Alfred 启动器
先问清用户要不要，不主动塞。

## 公司环境坑(2026-08 vivo 入职实测)
- 公司飞书**明令禁止发图片**——用户说"明面上说不让发"= 公司 IT 管控，**不是应用权限/配置问题，别去查飞书权限白费功夫**。
- 头两周新环境勿冒险：先摸清 IT 政策(能否访问外部域名如 pmlophy.com、能否装软件)，再决定深入用 AI 工具。
- 外接屏可能接了但键盘在笔记本上 → 主工作仍靠笔记本屏，凑合为主，别过度折腾。

## 隐私边界铁律(公司电脑=监管现场，用户已定，勿再劝)
用户明确：**公司电脑全程 IT 监管**(Web 网关/DLP/代理审计)——"能访问罗宾/杰西卡 ≠ 私密"，走公司网络(含公司 Wi-Fi)即被记录。用户已拍板的公私边界，未来会话直接遵守，别再建议他在公司机上配私人工具：
- **私人笔记**(Obsidian notes-vault)→ 不在公司电脑同步/安装，只在**手机**(走蜂窝流量,连 R2 Remotely Save)看。
- **私人 AI 工具**(切号工具、个人 Codex/Cursor 工作流、罗宾对接)→ 不装公司电脑，回手机/家里用。切号类工具在职场最敏感，DLP 可能直接判违规软件，优先级最高别装。
- **公司 M365 Copilot** = 只装工作内容、只登公司账号，绝不碰个人私密(租户内管理员可审计)。个人账号(私人 GitHub/邮箱/罗宾)一律不登公司机。
- 敏感/私密/规划对话在**手机 + 蜂窝流量**聊(不走公司 Wi-Fi)；公司电脑上只聊工作或无关痛痒的事。
- 若用户已在公司机装了私人工具，主动提醒风险，但**尊重决定**——他要留着就留着，只把边界讲清。
- 一句话原则：**公司电脑=工作现场(有监控)，手机=私人空间(蜂窝)。公私分开，各回各家。**

## 验证
- 改完缩放/字体后问用户屏幕是否清爽，让他亲测为准(用户亲测才算数铁律)。
- 不主动重启、不改系统关键配置(公司机权限可能受限)，只给用户自助步骤。
