# 原型标注标准（契约）

## 1. 标注单元与生命周期

- 一个 PRD 对应一套标注，不是全站全量 CMS。
- 在该 PRD 套件目录下维护 `annotations/` 源文件；编译产物覆盖写入原型的 `annotation-kit`。
- 该 PRD 评审/上线结束后，这套标注从原型端下线；源文件在 PRD 侧留档。
- 多个 PRD 并行时，各套标注独立共存，禁止把上一 PRD 的标注继续挂在原型上，禁止跨 PRD 拼成一套。

## 2. 什么内容进标注

- 只写**对着界面才说得清**的内容：按钮点下去发生什么、列含义、弹窗字段与校验、区域受什么权限约束等。
- 不写业务背景、需求价值、流程叙述；字段类事实以字段清单 TSV 为准。

## 3. 块怎么切

- 按**功能点**切，不按页面大区；判据：这块能否被单独打回重做。
- 典型块：筛选区、新建入口、数据表格、行操作、权限控制、弹窗内各分组、页脚操作、整页规则（`page-global`）。

## 4. 六个页签形态（固定）

每个标注块详情须包含下列六个页签（`###` 标题名固定）：

| 页签 | 形态 |
| --- | --- |
| 页面内容 | 一到三句概述，不写规则 |
| 交互说明 | 分项列表，每项一个动作；分项用 `1)` 编号 |
| 业务规则 | 分项列表，每项一条规则；分项用 `1)` 编号 |
| 字段说明 | 四列表格：**字段名称 / 是否必填 / 是否可编辑 / 约束与校验**；纯动作块写「本块不涉及字段」；禁止「见 §」「参见」指路 |
| 待确认 | **产品未定项**（写标注时从 PRD 发现，只读）与**评审问题**（面板录入，可勾选已解决并填解决方法，可导出待办；导出仅含评审问题）分两来源展示 |
| （面板） | 界面**不展示**来源行、文件路径；溯源仅 `config` 的 `sourceRefs`，编译时校验覆盖率 |

## 5. 角标与屏幕状态

- 角标编号单位是**当前屏幕状态**，不是整页一张表。
- 配置项 `screenState`：宿主页默认 `host`（可省略）；弹窗、抽屉等叠加态须写独立 `screenState`，同一路由内唯一。
- 同一 `screenState` 内 `id` 从 `1` 连续递增；不同 `screenState` 各自从 `1` 开始。
- **同一时刻只显示一套**：弹窗对应状态可见时，只渲染该状态组角标，宿主页 `host` 组隐藏。
- 分项列表在 Markdown 中统一用 `1)` 形式编号（与角标 `id` 无关）。

## 6. 发版前置

在项目根依次执行且**全部成功**才允许发版：编译 → 校验（含源码锚点与路由）→ 构建。任一步失败不得绕过、不得放宽判据。
