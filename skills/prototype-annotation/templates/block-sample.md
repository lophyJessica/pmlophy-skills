## 需求描述：【示例列表 · 筛选区】

### 页面内容
本块说明列表页顶部筛选区的查询条件与重置行为，不涉及表格行内操作。

### 交互说明
1) 点击「查询」：按当前条件刷新列表，保留页码为第 1 页。
2) 点击「重置」：清空可编辑条件并恢复默认时间范围为「近 7 天」。
3) 修改任一条件未点查询：列表数据不变，角标仍指向本筛选区。

### 业务规则
1) 时间范围必填；结束日期不得早于开始日期。
2) 状态多选为空时视为「全部状态」，不等于「无数据」。
3) 无列表查看权限的用户不展示本筛选区（整块隐藏，非禁用灰显）。
4) 查询中重复点击「查询」不叠加请求，以最后一次为准。

### 字段说明
| 字段名称 | 是否必填 | 是否可编辑 | 约束与校验 |
| --- | --- | --- | --- |
| 关键词 | 否 | 是 | 最长 50 字，前后空格 trim |
| 状态 | 否 | 是 | 多选；枚举以字段清单 TSV 为准 |
| 时间范围 | 是 | 是 | 开始 ≤ 结束；跨度 ≤ 90 天 |
